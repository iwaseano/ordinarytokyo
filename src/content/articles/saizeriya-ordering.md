## A typical table-service flow

This sample demonstrates the structure for a chain restaurant guide. The prices are placeholders for display testing; a published review should be based on a real visit and clearly dated checks.

1. Find a table and check the menu.
2. Use the restaurant's ordering method, such as a table button or a staff member.
3. Point to a menu item and state the quantity.
4. Ask for the check when you have finished.

## Keep the order simple

Short, polite phrases are enough for a basic order. If a menu has item numbers, showing or reading the number can make the request clearer.

## What to verify on a real visit

Record the actual menu item, price, branch, ordering method, and any questions staff ask. Use those observations—not assumptions—to update this demonstration into a useful local guide.
